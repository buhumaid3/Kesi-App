# Getting Kesi onto iPhones: TestFlight runbook

The app is the same web game wrapped in a native iOS shell by **Capacitor 8**. **Codemagic** builds it on a Mac in the cloud and uploads it to **TestFlight**, so no Mac is needed. You create every account and key yourself; nothing secret goes into this repo or to Claude.

## What's in the repo

| File | What it does |
|---|---|
| `capacitor.config.json` | App ID `com.buhumaid.kesi`, name "Kesi", dark launch colours, status bar style |
| `ios/` | The Xcode project (generated by `npx cap add ios`, Swift Package Manager, iOS 15+). Commit it. |
| `assets/icon-only.png`, `splash*.png` | App icon (1024, no transparency) and launch screens, drawn by `tools/icon.html` |
| `tools/build.mjs` | `npm run build`: www → dist, voices re-encoded to 32 kbit/s (about 160 MB → 90 MB) |
| `codemagic.yaml` | The cloud build: checks, build, sign, upload to TestFlight |
| `www/engine/native.js` | Save kept in iOS Preferences, splash, status bar, haptics. Does nothing in a browser. |

To change the bundle ID, edit it in **two places**: `capacitor.config.json` (`appId`) and `codemagic.yaml` (`bundle_identifier`). Then run `npx cap sync ios`. Do this before step 2 below; after the app exists in App Store Connect, its bundle ID can't change.

## One-time setup (about 45 minutes, all in your accounts)

1. **Apple Developer Program**: enrol at developer.apple.com (99 USD a year). Enrolment can take a day or two to be approved.
2. **Bundle ID**: Certificates, Identifiers & Profiles → Identifiers → **+** → App IDs → App. Description "Kesi", Bundle ID explicit `com.buhumaid.kesi`. No extra capabilities needed.
3. **App record**: App Store Connect → Apps → **+** → New App.
   - Platform iOS, name **Kesi: Kenya Case Files** (the name must be unique on the store; if it's taken, try "Kesi – Kenya Case Files").
   - Primary language English (U.K.), bundle ID from step 2, SKU `kesi-001`, full access.
4. **API key for Codemagic**: App Store Connect → Users and Access → Integrations → App Store Connect API → Team Keys → **+**.
   - Name "Codemagic", access **App Manager**.
   - Download the `.p8` file (you can only download it once). Note the **Issuer ID** and **Key ID** shown on that page.
5. **Codemagic**:
   - Sign up at codemagic.io with GitHub and add the `buhumaid3/Kesi-App` repository.
   - Team settings (or Personal account settings) → Integrations → **Developer Portal** → Connect.
   - Name the key **`kesi_asc`** exactly, then paste the Issuer ID and Key ID and upload the `.p8`.
6. **Internal testers**: App Store Connect → your app → TestFlight → Internal Testing → **+** group "Team" → add yourself (and anyone on your developer account).

## Every build

```
# in the Codespace, after committing the work you want to test
npm version patch          # 0.1.0 → 0.1.1: the version testers see (optional for every build)
git push && git push --tags
```

- **A `v…` tag starts a build by itself.** You can also start one from the Codemagic dashboard: the app → **Start new build** → workflow "iOS to TestFlight".
- **How long:** about 12–20 minutes. Free accounts get **500 macOS minutes a month**, roughly 25–40 builds; after that it's $0.095 a minute.
- **What it does:** runs the case checks, builds `dist/`, copies it into `ios/`, sets version and build number, creates the signing certificate and profile, builds the `.ipa`, and uploads it.
- **After upload:** Apple processes the build for 10–30 minutes. Internal testers then get it in the **TestFlight** app on their iPhone.

## Store listing basics (needed before external testers or release)

- **Privacy** ("App Privacy" in App Store Connect): **Data Not Collected**. The game has no accounts, analytics, ads or network calls; progress stays on the phone.
- **Export compliance:** already answered. `ITSAppUsesNonExemptEncryption = false` is set in `ios/App/App/Info.plist`, so TestFlight won't ask.
- **Age rating:** answer the questionnaire honestly.
  - The game has murder investigations with no graphic images: infrequent mild violence and mature themes. Expect roughly **13+**, but Apple's questionnaire decides.
  - The open decisions on cases 75 and 77 (child deaths) may push the rating up. Settle those first.
  - The updated questionnaire (new 13+/16+/18+ tiers) must be answered or uploads get blocked.
- **Category:** Games → Puzzle (the plist also says puzzle games). Secondary: Adventure.
- **External TestFlight testers** (people outside your team, up to 10,000) need a short Beta App Review. Fill in TestFlight → Test Information: a description, a feedback email, and what to test.

## When something fails

| Codemagic says | Fix |
|---|---|
| `No matching profiles found` / signing errors | The bundle ID in `codemagic.yaml` must match step 2 exactly, and the integration must be named `kesi_asc`. |
| `Requires Xcode 26` / Swift package errors | Keep `xcode: latest` in `codemagic.yaml`. Capacitor 8 needs Xcode 26+. |
| `The bundle version must be higher` | Builds use Codemagic's build counter. If you uploaded by other means before, start a build again: the counter only goes up. |
| `npm test` failed | A case file broke. Run `npm test` in the Codespace and fix it before tagging. |
| Upload OK but no build in TestFlight | Wait 30 minutes (processing). Check the email Apple sends to the account holder. |

## Testing on a phone before TestFlight

`npm run play` in the Codespace, then open the forwarded port in Safari on the iPhone (same GitHub account). The game runs the same, minus the app-only parts: save mirroring, haptics, splash. Use it for quick checks; use TestFlight for the real thing.
